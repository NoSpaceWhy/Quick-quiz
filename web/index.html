About me

Who made this and why

This project was made by Space. I used ChatGPT to help with some of the code and ideas, which I want to be open about.

I had been thinking about making a simple, fun quiz app for a long time. I wanted to make it available on GitHub Pages so anyone can enjoy a quick quiz. I hope you like it!

Honestly, I used AI partly because I find web development a bit of a slog. I prefer low-level programming, but web apps do have great animations and visual appeal.

Found a bug or have a fix to contribute? Visit my GitHub repository and open a pull request (PR).
