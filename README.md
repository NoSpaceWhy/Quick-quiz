## Run

```powershell
python main.py
```

Open [http://127.0.0.1:8000](http://127.0.0.1:8000) in your browser.

Choose a topic from the menu before starting an online quiz. The random quiz option needs an internet connection.

To create a quiz, enter a question, four choices, and the correct choice. Add as many questions as you like, then start the quiz. Use **Previous** to revisit questions and change an answer before finishing.

Completed quiz attempts are saved in this browser's local storage. Open **Past quizzes** to review answers, replay an old quiz, delete one attempt, or delete all history. History stays on this device and browser, and is not synced to an account. Previously answered questions cannot be changed when revisiting them.

Use **Dark mode** in the header to switch themes. Choose a per-question timer of 15, 30, 45, or 60 seconds from the menu; unanswered questions are skipped when time runs out.

During a quiz, **Skip** advances without earning a point. Correct answers make the lamb stomp the snake, while incorrect answers make the lamb cry.
